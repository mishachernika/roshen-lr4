# Лабораторна робота № 4 — Магазин «Рошен»

Навчальний програмний продукт для звіту з дисципліни «Конструювання програмного забезпечення».
Варіант 13. Автор: Чернік Михайло, група ППЗ-41.

## Склад репозиторію

- `roshen_shop.py` — прототип обробки замовлень і розрахунку знижки.
- `metrics.py` — підрахунок метрик Холстеда та Спен.
- `tests/test_shop.py` — модульні тести прототипу.
- `lab4_report.docx` — звіт до лабораторної роботи.

## Запуск

```bash
python3 roshen_shop.py
python3 metrics.py
python3 -m unittest discover -s tests -v
```

Демонстраційний сценарій виводить `До сплати: 680.8`.
