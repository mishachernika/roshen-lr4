# Лабораторна робота № 4 — Магазин «Рошен»

Навчальний програмний продукт для звіту з дисципліни «Конструювання програмного забезпечення».
Варіант 13. Автор: Чернік Михайло, група ППЗ-41.

## Склад репозиторію

- `roshen_shop.py` — прототип обробки замовлень і розрахунку знижки.
- `metrics.py` — підрахунок метрик Холстеда та Спен.
- `tests/test_shop.py` — модульні тести прототипу (пакет T1).
- `tests/test_system_blackbox.py` — системні чорноящикові тести (пакет T2, ST-01…14).
- `tests/test_scenarios.py` — інтеграційні сценарні тести (пакет T3, IT-01…04).
- `lab4_report.docx` — звіт до лабораторної роботи №4.
- `ЛР5_Чернік.docx` — звіт до лабораторної роботи №5 (тестування та відлагодження).

## Запуск

```bash
python3 roshen_shop.py
python3 metrics.py
python3 -m unittest discover -s tests -v
```

Комплект ЛР5 містить 26 тестів: 8 модульних (T1) + 14 системних чорноящикових (T2) + 4 сценарні (T3); покриття 96%.

Демонстраційний сценарій виводить `До сплати: 680.8`.
